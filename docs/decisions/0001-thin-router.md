# 0001: プラグインは上流正典ドキュメントへの薄いルーターとする

- **状態**: 一部廃止 (2026-09-22。採用は 2026-08-01, PR #2 での判断を追記録)。「プラグインは薄いルーター」という全体方針は、対象だった metaphor 系プラグインの撤去 (#143) と、判定ロジックと正本を同梱する [0022](0022-repo-standards-bundled.md) で実態でなくなった — repo-standards はスクリプトとフック約 2,500 行を持つ。「上流に正典があるものは内容を複製せず、場所と読み方だけを書く」は現行
- **文脈**: 対象の metaphor / metaphor-cli は正典ドキュメント (CLAUDE.md・AGENTS.md・DEVELOPMENT.md・CONTRACT.md・llms.txt 等) が濃い。プラグインへ内容を複製すると、上流の変更のたびに二重メンテが必要になり、確実にドリフトする。
- **決定**: プラグインは「いつ・何を読むか」だけを想起させる薄いルーターとし、正典の内容を複製しない。SKILL.md には正典の場所 (パス・URL) と読み方 (grep レシピ・jq レシピ等) のみを書く。
- **影響**: プラグイン本文は上流のパス参照が中心になるため、保守の中心課題は「参照先の生存確認」になる。この検知を仕組み化したのが [0002](0002-freshness-architecture.md)。
